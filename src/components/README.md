# components

المكونات المشتركة فقط، بدون منطق أعمال خاص بشاشة معينة.

- `ui/` — عناصر واجهة أساسية قابلة لإعادة الاستخدام: زر، حقل، بطاقة، جدول، Modal، Toast.
- `layout/` — الهيكل العام: Sidebar، Header، Breadcrumbs، PageShell.

أي مكوّن مرتبط بميزة معينة يبقى داخل `src/features/<feature>/components/`.
