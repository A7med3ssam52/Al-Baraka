# components

المكونات المشتركة فقط، بدون منطق أعمال خاص بشاشة معينة.

- `ui/` — عناصر واجهة أساسية قابلة لإعادة الاستخدام: زر، حقل، بطاقة، جدول، Dialog، Sheet، Dropdown، Tooltip، Toast، Skeleton، Empty State.
- `layout/` — الهيكل العام: AppShell، Sidebar، Header، Breadcrumbs، PageHeader.

أي مكوّن مرتبط بميزة معينة يبقى داخل `src/features/<feature>/components/`.
